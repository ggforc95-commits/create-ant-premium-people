# 蚂蚁保高品质真人角色

`create-ant-premium-people` 是一套面向保险视觉设计的真人商业摄影 Skill，适用于三代家庭、职业人物、旅行、运动和人宠场景。视觉规范涵盖自然肤色、蓝白灰服装、四季搭配、人物互动和成图检查。

## 使用

将仓库下载为名为 `create-ant-premium-people` 的目录，放入支持 Agent Skills 的客户端的技能目录中。确保该目录下可直接找到 `SKILL.md`。生成或编辑图片需要客户端提供对应能力。

示例请求：使用 `$create-ant-premium-people` 生成一张 16:9 横图，两位约 25 岁的中国年轻人穿浅蓝和白色运动服，在清晨的河边并肩慢跑，视线朝前，左侧预留标题空间。
