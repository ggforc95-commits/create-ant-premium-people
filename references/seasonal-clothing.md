# 春夏秋冬服装系统
季节是人物设定的必填项。生成前必须先判断春、夏、秋、冬，再选择服装材质、袖长、层次和配饰；不能只改变背景，也不能让同一套衣服跨季节重复使用。

### 4.1 季节通用原则

- 季节感主要通过面料、袖长、叠穿层次和功能配饰表达，不依赖复杂季节背景。
- 所有季节均限定在浅蓝、深蓝、白色、浅灰色体系内；女性可按用户要求少量加入柔和粉色。
- 同一组人物的季节必须一致，不能有人穿羽绒服、有人穿短袖。
- 多人服装应协调但不穿成完全相同的制服，通过蓝色深浅、白灰比例和面料区分人物。
- 老人、儿童的服装通常比青年多一层，符合真实保暖需求。
- 职业制服以工作规范为优先，再通过内搭、外层和面料体现季节。
- 白底图也必须有季节信息，但不额外加入落叶、雪花、花朵等装饰，除非用户明确要求。

### 4.2 春季人物

视觉感受：轻盈、清爽、温和，适合家庭陪伴、踏青、旅行、校园和城市生活。

| 人群 | 春季服装建议 |
| --- | --- |
| 老人 | 浅灰或浅蓝针织开衫、白衬衫、深蓝休闲裤；材质柔软，层次清楚但不过厚 |
| 父母/中年 | 浅蓝衬衫、薄款风衣、浅灰针织衫、深蓝直筒裤 |
| 青年男女 | 轻薄夹克、衬衫、针织背心、白色内搭、浅蓝牛仔或休闲裤 |
| 儿童/学生 | 蓝白卫衣、针织开衫、长袖校服、浅灰运动裤 |
| 职业人物 | 制服外增加薄外套或长袖内搭；医生可用白大褂配浅蓝长袖衬衫 |
| 旅行人物 | 薄风衣、轻便双肩包、编织帽或棒球帽；不使用厚重户外装备 |

### 4.3 夏季人物

视觉感受：明亮、透气、轻松，适合旅行、运动、亲子和户外保障主题。

| 人群 | 夏季服装建议 |
| --- | --- |
| 老人 | 短袖棉麻衬衫、薄款POLO衫、宽松浅灰长裤；避免背心和过短下装 |
| 父母/中年 | 白色或浅蓝短袖衬衫、薄款针织上衣、轻薄长裤或及膝休闲裤 |
| 青年男女 | 简洁白T、浅蓝短袖衬衫、轻薄防晒外套、运动短裤或浅色长裤 |
| 儿童/学生 | 蓝白短袖校服、轻薄运动装、透气运动鞋 |
| 职业人物 | 保留职业制服，改用短袖或透气面料；户外劳动者需有遮阳帽、袖套等合理防晒装备 |
| 旅行人物 | 短袖、轻薄外套、遮阳帽、水壶、小型相机；服装简洁，不做沙滩度假夸张造型 |

### 4.4 秋季人物

视觉感受：沉稳、温暖、有层次，适合家庭、长辈保障、出行和职业主题。

| 人群 | 秋季服装建议 |
| --- | --- |
| 老人 | 深蓝或浅灰针织衫、浅蓝衬衫、薄毛呢外套、舒适长裤 |
| 父母/中年 | 深蓝夹克、浅灰针织衫、白色内搭、直筒长裤 |
| 青年男女 | 牛仔外套、针织开衫、卫衣、薄款冲锋衣，采用深浅蓝叠穿 |
| 儿童/学生 | 蓝白卫衣、针织背心、长袖校服、薄夹克 |
| 职业人物 | 长袖制服、薄工作夹克；室内职业保持轻量，户外职业增加防风层 |
| 旅行人物 | 薄冲锋衣、轻量户外包、长裤、登山鞋；配饰以深蓝、浅灰为主 |

### 4.5 冬季人物

视觉感受：安心、保暖、亲密，适合家庭守护、老人关怀、医疗和冬季出行。

| 人群 | 冬季服装建议 |
| --- | --- |
| 老人 | 深蓝或浅灰羊毛衫、保暖夹克、轻薄羽绒服、围巾；避免臃肿遮挡身体结构 |
| 父母/中年 | 深蓝毛呢外套、浅灰羽绒服、白色高领内搭、简洁长裤 |
| 青年男女 | 短款羽绒服、毛呢外套、连帽保暖夹克；可用蓝白灰叠穿增加层次 |
| 儿童/学生 | 保暖羽绒服、针织帽、围巾、长裤和冬季运动鞋；配饰不遮挡脸部 |
| 职业人物 | 制服外增加符合工种的保暖工作服；医生护士在室内仍以制服为主，不穿户外厚外套问诊 |
| 旅行人物 | 保暖外套、围巾、毛线帽、小型旅行包；不默认加入滑雪装备，除非主题需要 |

### 4.6 季节与角色组合检查

- 先写季节，再写每位人物的外层、内搭、下装和鞋子。
- 检查同组人物厚薄是否一致，同时保留老人和儿童略多一层的真实差异。
- 检查服装是否仍符合人物身份：医生像医生、司机像司机、学生像学生。
- 检查季节配饰是否遮挡脸、手或关键动作；围巾、帽子、水壶等每人最多一个重点配饰。
- 修改季节时，只替换服装和必要配饰，不改变人物身份、脸型、关系、动作、构图和光线基准。
